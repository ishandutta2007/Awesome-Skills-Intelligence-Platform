# Top Skills Intelligence Platforms Ecosystem
**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Skills Inference, Skills Graphs, Talent Marketplaces, Skills Gap Analysis, Ontology Management & Workforce Intelligence*
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Skills Intelligence**. These systems build and maintain skills taxonomies/ontologies, infer skills from resumes, job data, learning activity and work signals, power internal talent marketplaces, identify skills gaps, and support skills-based hiring, mobility, and workforce planning.

**Examples** include TechWolf, Gloat, SkyHive, Retrain.ai, Eightfold AI, Workday Skills Cloud, Lightcast, Degreed, Beamery, Cornerstone Galaxy, Cornerstone Skills Graph, Degreed Skills+, and Techmap (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for open skills ontologies, ESCO/O*NET tooling, skill extraction, knowledge graphs, and self-hosted career/skills intelligence platforms — ideal for HR tech teams, workforce planners, researchers, and organizations seeking transparent, interoperable skills data.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms
- **[TechWolf](https://www.techwolf.ai/)**  
  Skills intelligence platform that automatically infers and maintains workforce skills from existing HR and work data without relying primarily on self-assessments, feeding accurate skills inventories into other talent systems.

- **[Gloat](https://gloat.com/)**  
  AI-powered talent marketplace and skills platform focused on internal mobility, project matching, and dynamic skills-based workforce planning.

- **[SkyHive](https://www.skyhive.ai/)**  
  Skills AI platform that analyzes labor market and internal data to support reskilling, job architecture, and skills-based transformation.

- **[Retrain.ai](https://www.retrain.ai/)**  
  Skills and talent intelligence solution aimed at continuous workforce reskilling and alignment with business needs.

- **[Eightfold AI](https://eightfold.ai/)**  
  Leading talent intelligence platform that uses deep learning for skills inference, talent matching, internal mobility, and workforce insights at enterprise scale.

- **[Workday Skills Cloud](https://www.workday.com/)**  
  Native skills foundation within the Workday HCM ecosystem that infers, relates, and manages skills across recruiting, learning, performance, and talent processes.

- **[Lightcast](https://lightcast.io/)**  
  Labor market and skills data provider (formerly Emsi Burning Glass) offering rich skills and occupation intelligence for workforce planning and education alignment.

- **[Degreed / Degreed Skills+](https://degreed.com/)**  
  Learning experience and skills platform that connects skill development, learning content, and skills profiles for continuous upskilling.

- **[Beamery](https://beamery.com/)**  
  Talent lifecycle and skills-based platform supporting recruiting, CRM, and internal talent strategies with skills graph capabilities.

- **[Cornerstone Galaxy / Cornerstone Skills Graph](https://www.cornerstoneondemand.com/)**  
  Skills and learning ecosystem within Cornerstone that maps skills, powers personalized development, and supports talent mobility.

- **[Techmap](https://)**  
  Specialized skills and technology mapping solutions for workforce and talent intelligence use cases.

## Open-Source GitHub Projects
- **[Open Skills Management Tool (OSMT)](https://www.openskillsnetwork.org/osmt)**  
  Free, open-source tool from the Open Skills Network for creating, storing, managing, and publishing Rich Skill Descriptors (RSDs) to enable interoperable skills libraries.

- **[ESCO Skill Extractor](https://github.com/KonstantinosPetrakis/esco-skill-extractor)**  
  Open-source tool that extracts ESCO skills and ISCO occupations from unstructured text such as job descriptions and CVs using embeddings and similarity matching.

- **[ESCO / O*NET crosswalks & related tooling](https://esco.ec.europa.eu/)**  
  Official and community resources linking the European ESCO taxonomy with the U.S. O*NET occupational framework for cross-border skills interoperability.

- **[MIND Tech Skills Ontology](https://github.com/MIND-TechAI/MIND-tech-ontology)**  
  Comprehensive open-source ontology of technical skills, frameworks, libraries, tools, and concepts with rich relations for tech workforce applications.

- **[SkillAlign](https://github.com/Y4SSERk/SkillAlign)**  
  AI-powered career recommendation and skill-gap engine built on the ESCO knowledge graph, transformer embeddings, and vector search.

- **[SkillLens](https://github.com/xmanojpx/SkillLens)**  
  Open-source career intelligence platform using semantic NLP, knowledge graphs, and adaptive agents for explainable skills and readiness scoring.

- **[ESCOPlus](https://github.com/dkavargy/ESCOPlus)**  
  Framework that enriches the ESCO taxonomy with emerging digital skills extracted from community sources such as Stack Overflow.

- **[CaSk / capability & skill ontologies](https://github.com/CaSkade-Automation/CaSk)**  
  OWL ontologies for describing capabilities and skills (particularly in industrial/automation contexts) based on standards.

- **[SkillNet and large-scale skill graphs](https://github.com/)**  
  Research and community projects releasing large skill knowledge bases and graphs for agent and recommendation use cases.

- **[Open skills libraries, RSD collections & extractors](https://github.com/)**  
  Additional community repositories for skill taxonomies, embedding-based extractors, and lightweight skills-matching services.

### Additional Strong Open-Source Options
- Direct use of the public **ESCO** and **O*NET** datasets as foundational skills and occupation taxonomies.
- Neo4j or other graph-database implementations of skills hierarchies and adjacency relationships.
- Sentence-transformer / embedding pipelines for custom skill extraction from resumes and job postings.
- Jupyter or Streamlit dashboards for skills gap analysis on top of open taxonomies.
- Integration patterns that feed open skills data into existing HCM, LMS, or ATS systems.

**Frameworks for building custom systems**: Start with open taxonomies (**ESCO**, **O*NET**, **OSMT Rich Skill Descriptors**, or the **MIND Tech Ontology**), extract skills from text with open extractors or embedding models, store relationships in a knowledge graph, compute gaps and matches with vector search or graph queries, and surface insights via simple internal tools or existing HR systems. Local LLMs can assist with skill normalization, adjacency suggestions, and natural-language explanations of gaps.

## Disclaimer
- This is a **community-curated** list — not exhaustive and not an endorsement.
- Skills data is sensitive workforce information. Open-source and self-hosted solutions require appropriate security, access controls, bias monitoring, and compliance with employment and data-protection regulations.
- Skills inference models (commercial or open) can contain biases present in training data; human oversight and validation remain essential for high-stakes talent decisions.
